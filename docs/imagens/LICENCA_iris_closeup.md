O arquivo [iris_strip_ilustrativa.png](iris_strip_ilustrativa.png) é uma adaptação
criada para o pôster. A imagem foi remapeada de coordenadas cartesianas para polares,
recortando o anel da íris, e recebeu ajuste local moderado de contraste. A faixa serve
somente para explicar visualmente a normalização do tipo *rubber sheet*.

Ambas as imagens são ilustrativas. Elas não representam participantes, amostras,
saídas do conjunto de dados ou evidência diagnóstica do estudo.
